# Tarefa: Adicionar Botão de Reset de Filtros na Aba Vagas

## Contexto
Projeto: **VagasDev** — Job board de vagas tech com filtros (palavra-chave, modalidade, área, ordenação).
A aba "Vagas" exibe filtros em `src/components/vacancies/VacanciesPage.jsx`. O estado dos filtros é gerenciado em `src/App.jsx` via `vacancyFilters` e `updateVacancyFilters`.

## Objetivo
Adicionar um botão **"Limpar filtros"** que resete todos os filtros para seus valores iniciais:
- `keyword: ''`
- `modality: ''`
- `area: ''`
- `sort: 'recent'`

## Arquivos a modificar

### 1. `src/App.jsx`
- Criar constante `initialVacancyFilters` com os valores padrão (linha 29-34).
- Substituir o `useState` inline pela constante.
- Criar função `resetVacancyFilters` que chama `setVacancyFilters(initialVacancyFilters)`.
- Passar `onResetFilters={resetVacancyFilters}` para `<VacanciesPage />`.

### 2. `src/components/vacancies/VacanciesPage.jsx`
- Receber nova prop `onResetFilters`.
- No toolbar (`section.toolbar`), adicionar botão **"Limpar filtros"** ao lado dos filtros.
- Botão deve ficar desabilitado quando nenhum filtro estiver ativo (todos nos valores padrão).
- Estilo: botão secundário/outline, ícone opcional (ex: `rotate-ccw` ou `x`), acessível (`aria-label`).

## Requisitos de estilo
- Manter consistência visual com `App.css` existente (variáveis CSS, classes `.btn`, `.btn-secondary`, etc.).
- O botão deve aparecer alinhado à direita dos filtros, na mesma linha (grid/flex).
- Hover/focus states visíveis.
- Responsivo: em mobile, pode ir para uma nova linha abaixo dos selects.

## Acessibilidade
- `type="button"` explícito.
- `aria-label="Limpar todos os filtros"`.
- `disabled` quando filtros já estão limpos.
- Foco visível (`:focus-visible`).

## Testes manuais esperados
1. Aplicar qualquer filtro (ex: digitar palavra-chave, selecionar modalidade).
2. Clicar em "Limpar filtros" → todos os campos voltam ao padrão; lista de vagas atualiza.
3. Clicar novamente → botão desabilitado (já limpo).
4. Trocar de aba (Sites → Vagas) → filtros mantêm estado (não resetam automaticamente ao trocar de aba).

## Entregáveis
- `src/App.jsx` modificado.
- `src/components/vacancies/VacanciesPage.jsx` modificado.
- Nenhum novo arquivo.
